reference.md 「우리 공식에 붙는 제목 방법만」·「팀이 따를 규칙」. content.md: 사용자분이 백업 1을 정함.

제목 방법 (히트에서만 읽음)

  1. 가격 또는 기한을 앞에 둔다. (6만원에, 3만원으로, 9월 2일 마지막)
  2. 배 이름을 고유명사로 넣는다. (부관훼리, 퀸제누비아2, 코스타 세레나)
  3. 반전은 혜택 하나다. 힘듬·불평은 넣지 않는다.
  4. 의문형은 탈만할까/왜 팔릴까처럼 결정용일 때만.

팀이 따를 규칙 5줄

  1. 출발지, 가격 또는 기한, 배 이름, 반전 하나. 네 칸이 아니면 올리지 않는다.
  2. 가격은 구체 숫자로 앞에 둔다.
  3. 반전은 혜택이거나 탈만할까다. 힘듬 한탄은 쓰지 않는다.
  4. 독도 힘듬·줍줍·일반 팁·후기 재탕 제목은 쓰지 않는다. 울릉크루즈는 배 이름을 넣어 따로 쓴다.
  5. 월요일은 탈만할까/결정만. 크루즈시티 조회는 근거로 쓰지 않는다.
